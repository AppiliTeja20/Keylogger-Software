Educational use & consent notice

This application is a college demonstration of keystroke capture and local logging. It only records keys typed into the single Test Keyboard Area below, and only while recording is explicitly turned on. It never runs in the background, never hooks your operating system's keyboard, never runs outside this visible browser tab, and never sends any data over a network. Logs are written to a local file on this machine only.

Do not type real passwords, PINs, or other sensitive/personal information into the test area.

What this demo does — and deliberately does not do

Scoped capture only

Keystroke listeners are attached to a single test <textarea> element, not the page, window, or operating system. Typing anywhere else produces no events at all.

Consent & visibility

Recording cannot start until the consent box is checked, and a status indicator is always visible on screen whenever capture is active.

No global hook, no stealth

This app does not use OS-level keyboard hooks, native input drivers, or hidden/background processes. Closing the tab or stopping the server stops everything.

Local storage, no persistence

Events are appended to a plain local log file. Nothing is sent over a network, and nothing installs itself to run automatically on startup.
